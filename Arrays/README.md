# 💛 JavaScript Array Concept Practice

This repository is a dedicated playground to run quick scripts, experiment with built-in methods, and solidify my core understanding of JavaScript arrays. 

Everything is kept inside a single, straightforward folder to keep testing simple and fast. 🇮🇳

---

## 📁 Repository Structure

```text
└── array/                  # Single folder for all JavaScript array practice
    ├── 01_basics.js       # Testing array structure,syntax, mutability,properties ,iteration
          ├──01 practice questions # item discount calculation, average marks in marks array     
    ├── 02_ Array methods # Getting confident with .pop(),.push(),.shift(),.unshift()
    ├── 03_reductions.js    # Understanding the .reduce() method
    └── [New Scripts]       # New playground files are added directly here
```

---

## 🎯 Target Concepts

The code inside the `/array` directory focuses purely on building strong muscle memory for:
*   **Basic Manipulation:** Understanding zero-based indexing, `.length`, and modifying elements.
*   **Core Array Methods:** Testing how `.slice()`, `.splice()`, `.concat()`, and `.includes()` behave.
*   **Functional Iteration:** Mastering how data transforms when passing callbacks into `.map()`, `.filter()`, and `.reduce()`.

---

## 🛠️ How to Run the Scripts

You can execute any file locally using Node.js to instantly see how the array logic outputs to the console:

1. **Navigate to the array folder:**
   ```bash
   cd array
   ```

2. **Run your script:**
   ```bash
   node 02_callback_loops.js
   ```
