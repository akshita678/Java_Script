## 💻 Highlighted Projects

### 📊 Program 1: Grade Calculator Script
One of my first scripts! It takes user marks via a browser prompt and evaluates the academic grade.

```javascript
a = prompt("enter marks ");
if(a >= 80 && a < 100){
    console.log("A")
}
else if(a >= 70 && a < 89){
    console.log("B")
}
else if(a >= 60 && a < 69){
    console.log("C")
}
else if(a >= 50 && a < 59){
    console.log("D")
}
else{
    console.log("E")
}
```
